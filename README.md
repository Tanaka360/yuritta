# YURITTA — AI Study Platform

> Named after Yuritta — mother of the founder.
> Built so that every African student has a professor available 24/7.

## Subjects Supported
- Economics
- Law  
- Medicine
- Accounting

## Pages
| File | Purpose |
|------|---------|
| `index.html` | AI tutor — ask anything, upload notes |
| `quiz.html` | AI-generated timed quizzes by subject and topic |
| `progress.html` | Score history and performance tracking |

## Stack
- Pure HTML, CSS, JavaScript
- Anthropic Claude API
- Vercel (hosting + auto-deploy)
